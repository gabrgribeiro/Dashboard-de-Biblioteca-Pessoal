# 📚 Personal Library Dashboard

Dashboard para gerenciamento de uma biblioteca pessoal.

O projeto permite cadastrar e organizar livros, acompanhar o progresso
de leitura e visualizar estatísticas da biblioteca.

> 🚧 Projeto em desenvolvimento

---

## 🎯 Objetivo

Este projeto está sendo desenvolvido como forma de praticar
desenvolvimento web e evoluir gradualmente de uma aplicação frontend
para uma aplicação full-stack.

---
